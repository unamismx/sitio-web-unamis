# Sitio web institucional de UNAMIS

Sitio estático de la Unidad de Atención Médica e Investigación en Salud (UNAMIS).

## Vista local

Desde esta carpeta:

```sh
python3 -m http.server 4174 --directory dist
```

Abra `http://127.0.0.1:4174/` en el navegador.

## Publicación

El contenido público del sitio se encuentra en `dist/`.
